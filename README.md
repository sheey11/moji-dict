# Moji 辞書

MOJi辞書を利用する、macOS ネイティブの日本語辞書クライアントです。画面はすべて SwiftUI と macOS のネイティブコントロールで構成し、通信には `URLSession` を使用しています。

アプリアイコンには、Apple App Store で公開されている MOJi辞書の現行 iOS アイコンを使用しています。アイコンの著作権は
MOJi/Krosea に帰属します。本プロジェクトは非公式の個人向けクライアントです。

![Screenshot](https://github.com/sheey11/moji-dict/blob/main/images/screenshot.png)

## 主な機能

- 入力後 180 ms のデバウンス検索
- 単語、文法、例文、過去問のグループ表示と絞り込み
- 初期状態では単語の検索結果を表示し、サイドバーには漢字と読み仮名だけを表示
- システム標準のツールバー検索項目を使用し、macOS 26 では統一された Liquid Glass デザインを採用
- ルビは漢字部分だけに付け、確実に分割できない場合は上下 2 行の表示にフォールバック
- macOS の「辞書」に近い記事レイアウトで、中国語と日本語の語義をネイティブ表示
- 日本語の語義と例文をシステム標準機能で分かち書きし、語句にポインタを重ねると下線が付き、そのまま再検索可能
- 各語義の直後に対訳例文を表示し、関連語はポインタを重ねると下線が付き、そのまま再検索可能
- Forvo の公開単語ページから取得した日本語音声をネイティブ再生し、話者の国と性別を表示
- ツールバーの戻る／進むボタンと、`⌘[`／`⌘]` ショートカットに対応
- 単語ページの末尾から、対応する MOJi 公式ページ、macOS の「辞書」、Forvo の発音ページを表示可能
- メールアドレスによるネイティブログインに対応し、ログイン状態とトークンを macOS キーチェーンへ暗号化して保存
- 古くなったリクエストを自動的にキャンセル
- 検索結果と単語の詳細はメモリ上だけにキャッシュ
- ブラウザの Cookie、Local Storage、パスワード、トークンは読み取りません
- パスワードは保存せず、ログアウト時にキーチェーン内のセッションを削除
- 閲覧履歴は実行中の戻る／進む操作にだけ使用し、ディスクには保存しません

## 利用する API

現在は MOJi の Web サイトで使用されている、以下の 4 つのエンドポイントを利用しています。

- `GET /app/mojidict/api/v2/search/all`
- `GET /app/mojidict/api/v1/word/detailInfo`
- `POST /app/mojidict/api/v1/word/related`
- `POST /app/mojidict/api/v1/account/unifiedLogin`

いずれも非公開かつ安定性が保証されていないプライベート API です。予告なく変更される可能性があり、レート制限やセキュリティ検証の影響を受ける場合もあります。本プロジェクトは個人での研究・利用を目的としており、大量取得、再配布、商用利用には適していません。

発音は Forvo の公開単語ページを単語ごとに 1 回だけ読み取り、音声ファイルを直接ストリーミングします。取得結果は実行中のメモリにだけキャッシュし、音声ファイルの保存や再配布は行いません。Forvo のページ構造や利用条件が変更された場合、この機能は利用できなくなる可能性があります。

## リリース

`Info.plist` のアプリバージョンと一致する `v*` タグを push すると、GitHub Actions がテスト、パッケージ作成、署名の検証を行い、バージョン付きの `.zip` と SHA-256 チェックサムを GitHub Releases に公開します。

```bash
git tag v0.13.0
git push origin v0.13.0
```

タグがすでに存在する場合は、GitHub の Actions ページから `Build and Release` を手動実行し、対象のタグを入力することで再ビルドまたは Release の添付ファイル更新ができます。通常のブランチへの push では Release は作成されません。

## 既知の制限

- 完全なネイティブ詳細表示は、現時点では通常の単語だけに対応しています。文法、例文、過去問については検索結果の概要を表示します。
- メールアドレスでのログインには対応していますが、お気に入り、メモ、会員向けコンテンツには未対応です。
- アプリは一時的な `URLSession` を使用するため、終了すると検索キャッシュは自動的に消去されます。ログインセッションはキーチェーンから復元します。
- 本プロジェクトは MOJi の公式クライアントではなく、MOJi 公式とは一切関係ありません。
