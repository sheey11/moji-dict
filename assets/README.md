# App icon source

`MOJiAppIcon-1024.png` is the 1024×1024 artwork served by Apple's App Store
CDN for app ID `1021094295` (`MOJi辞書: 日语专业学习词典`, version 8.42.0)
on 2026-07-30.

Source listing:
https://apps.apple.com/jp/app/id1021094295

The artwork belongs to MOJi/Krosea. It is included here only for this personal,
unofficial client.

The App Store artwork is an opaque square intended to be masked by iOS.
`MOJiAppIcon-masked-1024.png` applies a 224 px transparent corner radius so the
regular macOS app icon matches its iOS presentation.
